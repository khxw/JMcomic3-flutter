## 更新内容

- 首页布局：首次启动默认使用“图文2”展示形式。
- 首页布局：首次启动默认每行显示 3 列漫画。
- 网络线路：启动时自动并行测速并选择最快的可用 API 线路。
- 网络线路：启动时自动并行测速并选择最快的可用图片线路。
- 离线书架备份：新增阅读进度导出，包含最新章节、页码和阅读时间。
- 离线书架备份：导入时合并并恢复阅读进度，旧备份仍可正常导入。
- 阅读进度：退出阅读器后等待最后一次进度写入完成，再刷新漫画详情和下载详情。
- 阅读进度：从阅读器返回时在线详情页和离线详情页都会重新读取最新章节与页码。
- 设置：新增“离线书架备份”分组，支持导出和导入 JSON 备份。
- 离线书架备份：包含漫画条目、分组和加入时间，导入时合并并跳过重复漫画。
- 图片长按菜单：移除“保存图片到文件”和对应保存逻辑。
- 图片长按菜单：仅保留“保存图片到相册”。
- 在线收藏：长按漫画可移动到已有收藏夹。
- 在线收藏：移动时支持直接新建收藏夹并自动移入。
- 在线收藏：重做顶部概览卡，显示当前收藏夹、收藏数量、排序方式和刷新入口。
- 在线收藏：隐藏重复的分页状态行，减少纵向占用并突出漫画封面。
- 在线收藏：排序和收藏夹筛选改为带文字的紧凑按钮，提升可读性。
- 书架：登录后新增“离线书架 / 在线收藏”切换。
- 书架：在线收藏复用账号收藏的分页、文件夹、排序和刷新功能。
- 书架：未登录时隐藏在线收藏入口，仅显示离线书架。
- 提示 UI：签到、检查更新及其他操作提示统一为居中的圆角卡片。
- 提示 UI：加载中的检查更新和签到提示使用静态图标，不再旋转。
- 个人中心：昵称、UID、等级与等级称号改为三排布局。
- 启动优化：配置项改为并行加载。
- 漫画详情加载：先显示标题、作者和封面，详情数据后台补全；增加持久缓存，下拉刷新强制获取最新数据。
- 个人中心：账号卡移除个性签名
- 阅读页：下一章改为原页面加载，不再重建整个阅读页。
- 阅读页控制栏：顶部和底部栏改为悬浮覆盖，显示或隐藏时漫画不再移动。
- 账号收藏：漫画详情页新增收藏按钮，仅登录状态显示。
- 退出账号：个人中心新增退出账号功能，退出后保留设置和本地数据。
- 记住账号密码：登录弹窗和初次登录页新增复选选项，支持保存及清除凭据。
