## 更新内容

- 书架：登录后支持“离线书架 / 在线收藏”切换，未登录时隐藏在线收藏入口。
- 在线收藏：支持分页、收藏夹筛选和排序；长按漫画可移动到已有收藏夹，或新建收藏夹后直接移入。
- 登录账号：登录成功后自动刷新等级、经验、硬币、徽章等账号信息，并自动更新签到状态。
- 离线书架备份：支持导出和导入书架、分组、加入时间，以及最新章节、页码和阅读时间。
- 网络线路：启动时并行测速 API 和图片线路，自动使用延迟最低的可用线路，全部失败时保留当前线路。
- 图片长按菜单：移除“保存图片到文件”功能。

## 构建

- Android `arm64-v8a` Release APK。
